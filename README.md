# Квартира — пространство для жизни

Тестовый сайт с вращаемой 3D-моделью квартиры и первым эскизом перехода от трёх комнат к двум отдельным комнатам и большой кухне-гостиной.

## Что есть

- Исходная схема: три комнаты + отдельная кухня 16,91 м².
- Вариант 01: кухня-гостиная около 28,16 м², большой стол на шесть мест.
- Вариант 02: мастер-спальня с гардеробной и приватным проходом в ванную; кухня и гостиная отдельные.
- Три палитры: дуб/шалфей, тёплый минимализм, орех/терракота.
- Вращение, масштаб, вид сверху, приближение к кухне, полные/срезанные стены, переключатель мебели.
- PNG текущего ракурса и ссылка, сохраняющая вариант, палитру, режим камеры и переключатели.
- Исходный план, два кадра видео, пояснения к точности.

## Запуск

Нужен Node.js 20 или новее. Устанавливать npm-пакеты не требуется: Three.js 0.170.0 и OrbitControls лежат в `dist/vendor/`.

```sh
npm start
```

Откройте http://127.0.0.1:4186. Для просмотра нужен HTTP-сервер: двойной щелчок по HTML не подходит для ES-модулей.

```sh
npm test
```

Альтернативный запуск без Node: `python3 -m http.server 4186 --directory dist`.

## GitHub Pages

Сайт: https://daniilyuzhanin.github.io/apartment-studio-/
В текущем удалённом репозитории содержимое `dist/` находится в корне; Pages публикует `main / (root)`. При обновлении переносите файлы из `dist/` в корень репозитория.

Для нового репозитория с полной локальной структурой можно использовать workflow:

1. Создайте репозиторий и загрузите содержимое этой папки в ветку `main`, включая `.github/workflows/pages.yml`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Publish apartment studio → Run workflow** (или сделайте новый push в `main`).
4. После успешного `deploy` адрес появится в **Settings → Pages** и в окружении **github-pages**.

Workflow публикует только `dist/`. Приложение использует относительные пути и работает как в корне домена, так и под `/имя-репозитория/`. На бесплатном GitHub Pages репозиторий должен быть публичным; другие возможности зависят от тарифа. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Для любого другого статического хостинга достаточно папки `dist/`. В приложении нет аккаунтов, аналитики, серверного хранилища и запросов к внешним сервисам во время просмотра. Исходное полное видео и PDF с титульным блоком в сайт не включены: используются только план и два интерьерных кадра.

## Где дорабатывать

- `dist/layout.js` — варианты, площади, помещения, палитры, параметры ссылок.
- `dist/scene.js` — геометрия стен и проёмов, мебель, свет, камера.
- `dist/app.js` — интерфейс, переключатели, сохранение снимка.
- `dist/style.css` — оформление и адаптация под узкие экраны.
- `docs/design.md` — источники, допущения и границы концепции.

Изменения в `layout.js` не являются полноценным BIM-редактором: при изменении стен следует синхронно обновлять `scene.js`. Это простая основа для следующих итераций.
