# Квартира — 12 вариантов планировки

[Открыть сайт](https://daniilyuzhanin.github.io/apartment-studio-/)

Интерактивная 3D-модель с 12 разными конфигурациями перегородок, палитрами, видами сверху и отдельным ракурсом санузла. Санузел у входа повторяет присланную схему с дверью 80 см, шкафом, умывальником, унитазом и душевой зоной. На сайте размещены оба новых референса.

[Санузел: три дизайна](https://daniilyuzhanin.github.io/apartment-studio-/bathroom.html?v=3) — камень с дубом, травертин и олива с орехом. Семь ракурсов, крупные изображения из той же модели, три сценария света и четыре листа чертежей. По новой правке шкаф уменьшен с 700 до 503 мм в глубину, чтобы фасад был вровень с неизменённой шахтой. Справа от шахты показана ниша 354 × 503 мм с пятью полками.

Размеры из квартиры соседей этажом выше используются как временный ориентир. Площадь у соседей — 73,45 м²; в первом PDF — 75,69 м². Нужны собственные обмеры. Варианты основаны на подтверждении пользователя о переносимости межкомнатных перегородок; толстые стены, наружные простенки, окна, шахты и мокрые зоны закреплены между вариантами.

## Запуск

В репозитории GitHub сайт находится в корне: запустите `python3 -m http.server 4186` и откройте http://localhost:4186. Установка npm-зависимостей не требуется.

В локальном архиве сайт находится в папке `dist`: запустите `python3 -m http.server 4186 --directory dist`. Для телефона и обмена ссылками используйте опубликованный сайт выше.

GitHub Pages публикует ветку main, папку /(root). Изменения этой ветки запускают публикацию.

## Доработка

- `catalog.js` — 12 сценариев, критерии и размеры из соседского PDF.
- `layout.js` — комнаты, площади, конфигурации и параметры ссылок.
- `architecture.js` — стены, двери, окна, сантехника и закреплённые элементы.
- `scene.js` — мебель, материалы, освещение и камера.
- `app.js`, `style.css`, `index.html` — интерфейс.
- `bathroom-data.js` — общая геометрия санузла, варианты отделки, свет и параметры ссылок.
- `bathroom-scene.js`, `bathroom-drawings.js` — подробная 3D-модель и четыре листа.
- `bathroom.html`, `bathroom.css`, `bathroom.js` — альбом санузла и переключатели дизайнов.

В локальном архиве эти файлы лежат в `dist/`, а проверки — в `tests/`. Проверка: `node --test tests/*.test.mjs` (Node 20+). Проверки геометрии не заменяют строительный проект.
